## 0.1.2 页面过渡修复

日期：2026-11-25。

核对本机 Everest 的 OuiFileSelect、OuiFileSelectSlot 和 Overworld 页面切换流程，保留原生等待及逐项延迟，以原生 Show 作为页面入场起点。新增 SavePageMotion，让原生卡片与自绘卡组使用共同的横向位移；布局坐标与页面位移分开，避免每帧覆盖入场效果。Overworld 在切换期间将 Current 清空，因此通过 Next 识别进入中的存档页，退出中持续绘制至位移完成。

新增 23 项页面过渡断言，累计 897 项通过。Release 编译及打包通过。未启动或关闭用户游戏，未查看屏幕；游戏内过渡、命名/辅助模式返回路径由用户验收。

## 0.1.3 菜单与搜索

日期：2026-11-25。

读取本机 Everest 的 TextMenuExt、OuiModOptions 实现后，使用原生 TextMenu.Button / Header、TextMenuExt.TextBox 和 menu/mapsearch 资源统一界面。菜单过渡与文字列表独立于存档编号和数据，退出动画完成后再释放控件与执行后续动作，停止输入时释放 TextBox 的事件订阅和输入占用。

新增独立搜索目录，覆盖卡组与所有成员。回车按精确名称、前缀、包含、多关键词、缩写的顺序定位；上下文和槽号参与兜底匹配。同分保持用户顺序。新 SearchSaves 绑定默认为 R，旧 FindDeck 配置不再使用。按用户追加要求移除 ReduceMotion 设置，布局动画始终启用。

页面闪烁修复新增 BeforeRender 同步，避免原生 Tween、Show/Hide 与不同 Depth 的实体更新先后造成错帧；绘制槽位时再确认一次坐标。退出阶段固定纵向布局，仅允许参与过渡的条目绘制，并保留屏外终点。累计 972 项断言通过，新增覆盖搜索目录/排名、菜单进出生命周期和页面过渡绘制门控。Release 构建通过，游戏内效果由用户验收。
