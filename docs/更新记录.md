## 0.1.6 — 2026-11-25

- 分类数据校验使用哈希集合补齐根条目，减少大量存档时的重复线性查找。
- Release 编译通过，978 项断言通过；保留原生加载器和菜单动画。未启动游戏或查看屏幕。
